## Selected projects

### [FitCV](https://github.com/longdang193/fitcv)

**Evidence-gated job matching and grounded CV workflow**

FitCV turns noisy job postings from uploads, Apify exports, and verified careers
portals into an inspectable shortlist, then generates tailored CVs only when
candidate evidence supports them.

`Python` `FastAPI` `SQLite` `LLM workflows`

[Technical Preview v0.1.0-preview.1](https://github.com/longdang193/fitcv/releases/tag/v0.1.0-preview.1)

**Governed starter kit for AI-assisted software development**

An open-source starter kit for coordinating coding-agent work with clear ownership,

[Architecture overview](https://github.com/longdang193/project-OS-starter/blob/main/docs/architecture.md)

### [LightRSI](https://github.com/longdang193/LightRSI)

**Context management runtime for long-running coding agents**

An independent fork of [LightRSI](https://github.com/zjunlp/LightRSI), an
open-source runtime for managing the conversation and tool history used by
coding agents. The fork changes context cleanup from broad task-level deletion
into precise, agent-directed release of obsolete messages and tool outputs.

It also adds restart-safe history recovery, provider-compatible forwarding,
Windows runtime hardening, cache diagnostics, and reproducible tests and
benchmarks.

`TypeScript` `Node.js` `Codex CLI` `Runtime recovery` `Benchmarking`

Transforms raw e-commerce events into BI-ready KPI layers, ML assets, and reporting datasets.

`SQL` `Python` `BigQuery` `Bruin` `BigQuery ML` `Looker Studio`
